# Test plan

1. Register and log in.
2. Reject duplicate email and invalid password.
3. Create a project and verify it persists after refresh.
4. Send a chat message and confirm both sides of the conversation are saved.
5. Generate all eight artifact types in demo mode.
6. Edit an artifact and verify the version increments.
7. Add a task, change status, and verify dashboard metrics.
8. Add a bug and update its status.
9. Confirm one account cannot access another account's project.
10. Verify backend/API errors are shown as useful messages.
11. Run `npm run build` in frontend.
12. Test a narrow/mobile viewport.
