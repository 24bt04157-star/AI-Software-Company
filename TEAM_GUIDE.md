# Manav Frontend

This bundle contains the existing project files assigned for review and further development.

## Important
- These are current baseline files, not proof that the assigned person independently authored all of them.
- Make a meaningful change in your assigned area, run and test it, and commit your own work from your own GitHub account.
- Do not upload this bundle as a ZIP file to the repository. Extract it and copy the files into the matching paths in your full project checkout.
- Avoid overwriting a teammate's newer work. Coordinate before editing shared files.
- Never commit `.env`, API keys, passwords, `node_modules`, or local database data.

## Suggested contribution
Improve a specific dashboard/UI feature, responsive layout, accessibility, and verify API integration.

## Suggested commit message
`Improve responsive frontend and dashboard interactions`
