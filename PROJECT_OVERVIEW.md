# Project overview

Title: AI Software Company — An Intelligent Multi-Agent Platform for End-to-End Software Development.

Core MVP: authentication, project creation, Business Analyst chat, SRS/user-story/architecture/sprint/estimate/UML/QA/API artifact generation, artifact editing, task board, bug tracker, and progress dashboard.

AI roles: Business Analyst, Solution Architect, Project Manager, Developer Assistant, QA Engineer.

No Gemini key: deterministic demo outputs are available and marked as demo. Live AI requires a Gemini API key in backend/.env. MongoDB is optional; local JSON persistence is used otherwise.

Limitations: this build generates project artifacts, not a complete production application. AI content must be reviewed and tested.
